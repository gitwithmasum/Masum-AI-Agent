# Masum AI Agent 1.0.0 — First Run

## Windows

Install the official Windows setup, start Masum AI Agent, and use the tray menu to open **First Run Guide**, **Mobile Pairing Info**, **Security Health Report**, and **Reliability Report**. Ollama and the selected local model must be available for the unified local AI brain.

## Android

Install only the final signed APK for the cleanest update path. Open Masum AI Agent and complete the numbered setup permissions. Set it as the Default Assistant, enable only the optional powers you actually want, pair it with the Windows companion on trusted private Wi-Fi, then press **RUN FIRST-RUN READINESS CHECK**.

## Minimum smoke test

Say:
- Hey Cirilla, brain status
- Hey Cirilla, open VS Code on laptop
- Hey Cirilla, battery status
- Hey Cirilla, flashlight on
- Hey Cirilla, security status
- Hey Cirilla, reliability status
- Hey Cirilla, explain polymorphism in Bangla

Then test one reminder, one screen-read command, one camera OCR capture, and—only if you enabled call permissions—one non-sensitive call-control scenario.

Do not test payment, OTP, password or security-code flows with automation; those remain protected.
