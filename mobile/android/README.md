# Masum AI Agent Mobile v6.1

v6.1 adds a consolidated Security + Permission Center.

Checks include:
- microphone
- default assistant role
- SIM call control
- call/message notification access
- Accessibility Voice Control
- contacts
- outgoing-call permission
- reminder notifications
- camera / flashlight
- Modify System Settings
- Do Not Disturb access
- unified laptop bridge pairing

The center can open the relevant Android settings screens and test both the Windows bridge and unified AI brain.

Voice:
- Hey Cirilla, security status
- Hey Cirilla, permission status
- Hey Cirilla, laptop security status
- হেই সিরিলা, সিকিউরিটি স্ট্যাটাস

Security hardening:
- outgoing call/message/reply confirmations expire after 20 seconds
- passwords, PINs, OTPs, CVV/security codes remain protected
- payment/security confirmation screens are not auto-clicked
- arbitrary voice-to-shell execution remains disabled
- the unified brain dashboard remains localhost-only
